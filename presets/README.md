# 내장 프리셋

각 `*.json` 파일은 **고급 탭 → 설정 가져오기** 메뉴 또는 단축키 `Ctrl+I` 로 불러올 수 있는
프리셋입니다. 가져오기 후 일부 설정은 앱 재시작이 필요할 수 있습니다.

| 파일 | 스타일 | 폰트 | 추천 용도 |
|---|---|---|---|
| `minumsa_drama_style.json` | 민음사 세계문학전집 희곡 판본 | 본명조 / 부크크 고딕 | 시나리오 / 극본 형식 리플레이 |

## 새 프리셋 만들기

1. 앱에서 원하는 설정으로 조정
2. `Ctrl+E` (설정 내보내기) → `presets/your-name.json` 으로 저장
3. README 표에 한 줄 추가

프리셋 JSON 의 `_meta` 키는 사용자가 가독성을 위해 다는 메타데이터이며, 가져오기 시 자동으로 무시됩니다.
